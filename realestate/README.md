# 재개발·재건축 매물 비교 도구

관심 구역(한남2·4·5, 방배13, 성수1~4지구 등)의 **실거래가를 공공 API로 모으고**,
중개사에게 받은 **매물을 같은 기준으로 환산해 가격 메리트 순으로 줄 세우는** 스크립트 2개입니다.
Python 3.11 이상이면 되고, 따로 설치할 패키지는 없습니다.

| 파일 | 역할 |
|---|---|
| `zones.toml` | 구역 정의(시군구 코드, 법정동, 지번 본번, 주변 신축 평당가, 비례율) |
| `molit_trades.py` | 국토부 실거래가 API → 구역별 매매 실거래 `trades.csv` + 요약 `trades_summary.csv` |
| `listings_template.csv` | 매물 입력 양식(예시 4줄은 임의 숫자, 지우고 사용) |
| `rank_listings.py` | 매물 CSV → 지표 계산 + 순위 `ranked.csv` |

## 1. 인증키 발급 (최초 1회)

1. [공공데이터포털](https://www.data.go.kr) 가입
2. 아래 4개 API를 각각 **활용신청**합니다. 보통 바로 승인되고, 인증키는 4개 모두 같은 걸 씁니다.
   - 국토교통부_연립다세대 매매 실거래가 자료 ← 빌라 (재개발 핵심)
   - 국토교통부_단독/다가구 매매 실거래가 자료 ← 단독주택 (재개발 핵심)
   - 국토교통부_아파트 매매 실거래가 자료
   - 국토교통부_토지 매매 신고 자료 (선택)
3. 마이페이지에서 **일반 인증키(Decoding)** 를 복사합니다. Encoding 키를 넣어도 됩니다.

```bash
export MOLIT_API_KEY="발급받은키"
```

## 2. 실거래 수집

```bash
python molit_trades.py                       # 전체 구역, 최근 24개월, 빌라+단독+아파트
python molit_trades.py --zones 한남4구역 한남5구역 --types rh sh --months 36
python molit_trades.py --from 202401 --to 202609 --strict --out hannam.csv
```

- `--types`: `rh` 연립다세대, `sh` 단독다가구, `apt` 아파트, `land` 토지
- 결과의 **대지평당가(만원)** 가 재개발 구역 시세를 비교하는 기본 지표입니다.
- 한 번 받은 월은 `.cache/` 에 저장해서 다시 실행할 때는 API를 부르지 않습니다(최근 2개월은 신고 기한 때문에 매번 새로 조회).

### 구역 경계 맞추기 (중요)

API는 지번 단위 필터가 없어서 **법정동 전체** 거래가 내려옵니다. 예를 들어 보광동에는 한남2·4구역이 겹쳐 있습니다.
`zones.toml` 의 `bonbun` 에 구역 지번 본번을 채우면 구역 안 거래만 남습니다.

- 정확한 지번은 정비구역 지정 고시문, [정비사업 정보몽땅](https://cleanup.seoul.go.kr), 토지이음에서 확인하세요.
- `note` 에 적힌 대표 지번은 참고용이라 **확인이 필요합니다**.
- 단독다가구·토지 거래는 API에서 지번이 `3**` 처럼 가려져 나옵니다. 그래서 `지번매칭` 열이 `후보` 로 표시되고, 구역 안 거래인지 확정할 수 없습니다. `--strict` 를 주면 `일치` 한 거래만 남깁니다.

## 3. 매물 순위 매기기

`listings_template.csv` 를 복사해 매물을 입력합니다(엑셀로 편집해도 됩니다. 금액 단위는 **만원**).

| 컬럼 | 설명 |
|---|---|
| 감정가 | 종전자산 감정평가액. 감정평가 전이면 비워두기 |
| 비례율 | % (비우면 zones.toml 의 `default_ratio`) |
| 신축공급㎡ | 배정(희망) 평형의 공급면적. 예: 34평형 ≈ 112㎡ |
| 조합원분양가 | 해당 평형의 조합원 분양가(추정치라도) |
| 승계대출 | 이주비 등 승계하는 대출 |
| 지위양도 | Y / N. 조합원 지위 양도가 가능한 매물인지 |

```bash
python rank_listings.py my_listings.csv --trades trades.csv --out ranked.csv
```

계산하는 지표:

```
권리가액        = 감정가 × 비례율
프리미엄        = 매매가 − 권리가액
추가분담금      = 조합원분양가 − 권리가액
총매입가        = 매매가 + 추가분담금
신축환산평당가  = 총매입가 ÷ 신축 공급평        ← 구역이 달라도 같은 기준으로 비교
안전마진%       = 1 − 신축환산평당가 ÷ 주변 신축 시세 평당가 (zones.toml nearby_new_ppp)
초기투자금      = 매매가 − 전세보증금 − 승계대출
실거래중위대비% = 매물 대지평당가 ÷ 구역 실거래 대지평당가 중위값
```

**정렬 기준**: 지위양도 불가 매물은 맨 뒤로 보냅니다. 나머지는 안전마진이 높은 순 → 신축환산평당가가 낮은 순 → 실거래 중위값 대비 낮은 순 → 대지평당가가 낮은 순으로 정렬합니다.
`점수기준` 열에 어떤 지표로 순위를 매겼는지 표시됩니다. 감정가가 없는 매물은 대지평당가로만 비교되니, 순위를 해석할 때 같은 기준끼리 보세요.

## 직접 확인해야 하는 것

이 도구는 숫자 비교만 합니다. 아래는 매물마다 따로 확인하세요.

- **조합원 지위 양도 제한**: 투기과열지구에서는 재개발은 관리처분인가 이후, 재건축은 조합설립인가 이후 원칙적으로 양도가 금지되고 예외 요건이 있습니다. 위반 매물을 사면 현금청산 대상이 됩니다.
- **토지거래허가구역**: 실거주 의무, 갭투자 불가 여부를 확인하세요.
- **입주권 개수**: 지분 쪼개기, 다물권자, 1+1 분양 여부
- **사업 단계별 리스크**: 사업시행인가, 관리처분, 이주, 착공 일정과 추가분담금 변동 가능성
